Teaching a model to read a face

    What happens to a photo

    Five steps run between an uploaded photo and a predicted emotion, in this order:

    1. 01

      Read as grayscale

      Color is discarded — expression is read from shape and shading, not skin tone or lighting color.

    2. 02

      CLAHE contrast normalization

      Adaptive histogram equalization evens out lighting differences across photos, so a dim photo and a bright one land on comparable footing.

    3. 03

      Three convolution blocks

      Stacked 3×3 convolutions with batch normalization build up from edges and creases to larger structures like a furrowed brow or a raised lip corner.

    4. 04

      Channel attention

      A small side network looks at the feature map as a whole and re-weights each channel — turning up the features that matter for this particular face, turning down the ones that don't.

    5. 05

      Softmax over eight classes

      The network outputs a probability for each of the eight expressions; the highest one is the prediction shown above.
